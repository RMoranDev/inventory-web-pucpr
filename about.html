Sobre o projeto

Um site de estoque feito só com HTML, CSS e JavaScript.

O Inventory Web é um trabalho acadêmico que mostra na prática como estruturar, estilizar e dar vida a um site sem frameworks: menu compartilhado, formulário com validação e leitura de dados enviados pelo método GET.

Tecnologias

Três linguagens, nenhum atalho

Só os fundamentos da web, cada um com seu papel.

HTML

  • Tags semânticas: header, nav, main, section e footer
  • Formulário com métodos e GET em campo
  • Caminhos relativos para os recursos

CSS

  • Visual moderno com sistema flexbox e grid
  • Layout responsivo
  • Estilos em arquivo separado, na pasta estilos

JavaScript

  • Menu e rodapé carregados com fetch
  • Validação nos campos do formulário
  • Leitura dos dados do GET com JavaScript e URLSearchParams
